PROJECT 01: PROGRESSIVE ELECTRICITY BILLING

This folder contains the complete first Python case study:
- Problem statement
- Objectives
- Assumptions
- Algorithm
- Flowchart (text version)
- Pseudocode
- Python source code
- Test cases and expected results
- Sample output
- Conclusion

HOW TO RUN
1. Install Python 3.
2. Open a terminal in this folder.
3. Run: python main.py

IMPORTANT
The assignment gives the case-study topic but does not specify tariff values.
Therefore, the slab rates, fixed charge, surcharge, and rebate used here are
clearly stated assumptions for this academic program. They are not official
electricity-board tariff rates.
